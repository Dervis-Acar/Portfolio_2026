Core Domain Algorithms

The app does not rely on hardcoded puzzles; instead, it uses a highly concurrent build-time generator to construct valid, unique boards dynamically.

1. Puzzle Generator

  • Random Solution Generation: Starts by placing N queens on an empty NxN grid using the Minimum Remaining Values (MRV) heuristic. Ensures no row, column, or diagonal touches.
  • Weighted Flood-Fill: Region boundaries are mapped around generated queen "seeds" using a weighted flood-fill algorithm, guaranteeing one queen per region.
  • Quality Assurance & Validation: Puzzles are filtered based on compactness rules, and both the Solver and Deduction Engine must verify that the puzzle has exactly one unique solution.

2. Puzzle Solver (Backtracking)

The PuzzleSolver determines whether a randomly generated grid is mathematically valid.

  • Forward Checking (Propagation): Placing a queen immediately removes conflicting cells from remaining unassigned rows.
  • Solution Limit: Halts the search after finding 2 solutions to prove uniqueness quickly.

3. Deduction Engine

Unlike the brute-force Solver, the DeductionEngine mimics human reasoning to provide hints and determine difficulty.

  • Techniques: Detects Singletons, Line Locks, and Subset Locks.
  • Speculative Passes: Attempts hypothetical placements to check for immediate contradictions ("dead-ends").

Game Mechanics & State

Game Engine

The GameEngine acts as the pure Kotlin state machine for a live puzzle session.

  • Undo/Redo Stack: Manages historic states, capturing user moves to allow infinite reversions.
  • Auto-Mark System: Automatically inserts "Cross" markers on all adjacent, same-row, same-col, and same-region cells to reduce tedious tapping.
  • Revert to Mistake: Dynamically unwinds state history backwards until the exact incorrect cell is isolated, placing a pulsating red highlight over it.

Rule Engine Validation

The RuleEngine is responsible for real-time validation checks during gameplay. It instantly identifies conflicts (Row Duplicate, Column Duplicate, Region Duplicate, Adjacent Queens) and flags them for the UI renderer.

Progression & Campaign

The progression system is structured as a directed campaign graph rather than a simple linear list. Each CampaignNode ties to a specific puzzle ID, grouping them by difficulty or introduced techniques. The state correctly resolves the nextPuzzleId upon level completion for seamless transitions.

The Player Profile tracks statistics over time (perfect clears, hints used, mistakes made) and rewards base experience scaled by the puzzle grid size and difficulty.
