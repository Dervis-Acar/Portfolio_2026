RAG System

A comprehensive, tenant-isolated Retrieval-Augmented Generation web application. This platform enables users to securely upload documents, process them into a private vector knowledge base, and interface with an AI assistant that cites their own data. Built 100% independently.

Core engineering features

security

Auth & Workspace Isolation

JWT-based Identity with email verification. Strict tenant isolation ensures all documents, chunks, and chats are scoped by workspaceId derived securely from the backend token.

account_tree

Async Ingestion Pipeline

A robust job chain: Malware Scan → Text Extraction → Chunking → Embedding → Vector Indexing. Features real-time UI progress tracking via IngestionJob entities.

forum

Streaming Chat & Citations

Real-time LLM responses grounded strictly in user documents. Includes a citation panel showing the exact source document name and text excerpt that generated the answer.

tune

Assistant Configuration

Per-workspace settings to control AI behavior: tone, output length, strict grounding limits, language, and custom system instructions.

shield_lock

Protection & Limits

Cloudflare Turnstile integration, per-user rate limiting (uploads/hr, chats/min), size validations, and automated malware scanning quarantine flows.

monitoring

Admin Dashboards & Analytics

Internal analytics tracking product events. Features custom Chart.js dashboards for usage overview, ingestion health, conversions, and abuse detection.

Advanced AI Capabilities

01 // Automated workflows

Predefined AI workflow templates allowing users to run complex tasks instantly: Email Drafting, Sales Responses, Support Tickets, Compliance Checks, Lead Extraction, and Policy Summaries.

02 // Proposal & quote generator

A specialized sales use-case that creates professional customer quotes by looking up pricing information directly from the uploaded knowledge base.

03 // PII anonymization showcase

Showcases advanced data privacy capabilities by scanning input text and automatically detecting/highlighting Personally Identifiable Information (Names, Emails, Phone numbers) before processing.
