RAG System

A multi tenant knowledge platform. Upload your documents, ask a question, get an answer that cites your own files.

  • GDPR compliant by design. Personal data is detected and masked before anything is processed.
  • Strict tenant isolation. Every document, chunk and chat is scoped to one workspace.
  • Answers you can check, streamed live and grounded only in your own documents.
  • Malware scanning and rate limits on every upload.
PRODUCTION PWA arrow_outward

Cairn

An installable app that runs a whole day: tasks, focus sessions, nutrition and startup idea validation.

  • Agentic AI voice assistant. Say a sentence and it becomes validated database writes, never free text.
  • Docker and nginx on Oracle Cloud Ubuntu, running on ARM64 with TLS I set up myself.
  • A CI/CD pipeline that refuses to ship if types, linting or the build fail.
  • Bilingual in Dutch and English at every layer, not bolted on as translation.

Queens Puzzle App

A premium puzzle game whose generator proves that every board it creates has exactly one solution.

  • A backtracking solver paired with a deduction engine that reasons the way a player does.
  • Clean Architecture across five separate Gradle modules.
  • Kotlin and Jetpack Compose, MVVM built on StateFlows.
  • OAuth 2.0 sign in against a C# ASP.NET Core backend.
